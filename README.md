# 🐉 Claude DM — D&D met AI Dungeon Master

Een browser-gebaseerde D&D app met Claude als Dungeon Master, ElevenLabs stem en dobbelstenen.

## Features
- 🤖 Claude Sonnet als Dungeon Master (volledig Nederlands)
- 🔊 ElevenLabs TTS met 10 stemkeuzes
- 🎲 Dobbelstenen met geluid (d4/d6/d8/d10/d12/d20/d100)
- 🎙️ Push-to-talk spraakherkenning
- ✅ Transcript bevestiging voor acties
- 📱 Geoptimaliseerd voor mobiel (iOS/Android)
